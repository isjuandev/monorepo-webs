# Verificación, criterios de aceptación y ejemplos globales

## 1. Lista de verificación final (todas deben ser "sí")

1. ¿El texto corresponde al estilo de motel seleccionado?
2. ¿El tono se distingue realmente de los demás tonos del catálogo (vocabulario, ritmo, intención)?
3. ¿La redacción es natural, clara y específica?
4. ¿Describe beneficios reales y no características inventadas?
5. ¿El titular comunica una propuesta de valor reconocible?
6. ¿Los CTA indican acciones concretas (verbo + objeto)?
7. ¿La reserva por WhatsApp está facilitada (enlace `wa.me` válido o marcador pendiente)?
8. ¿La visita presencial tiene una invitación apropiada?
9. ¿Las descripciones aportan información útil (tipo, equipamiento, tarifa, duración, condiciones)?
10. ¿Se evitan repeticiones y clichés?
11. ¿La voz de marca es consistente en toda la web?
12. ¿Los textos funcionan en escritorio y móvil?
13. ¿Se evitan promesas comerciales imposibles de verificar (privacidad absoluta, disponibilidad, mejor de…)?

Si falla un criterio importante, **corrige antes de entregar**. Si no puedes corregirlo por falta de datos, deja un marcador `[…_PENDIENTE]` y repórtalo.

## 2. Criterios de aceptación (medibles)

| Criterio | Aceptado si… |
| :-- | :-- |
| Datos | Cada precio, horario, servicio, dirección, número y promoción aparece en la fuente del usuario o es un marcador `_PENDIENTE` |
| Tono | Un lector podría identificar el tono sin ver el nombre; no hay palabras de la lista "desaconsejado" del tono |
| CTA | Hay un CTA principal por pantalla; ningún CTA vago; ningún CTA repetido literal > 2 veces por página |
| WhatsApp | Enlaces `https://wa.me/<dígitos>`; `text` codificado; sin números inventados |
| Visita | ≥ 3 invitaciones a visitar (presentación/galería, ubicación, cierre) o las que permita la estructura |
| Cliché | 0 apariciones de las frases prohibidas (§3); "experiencia", "exclusivo", "inolvidable", "único" ≤ 1 vez por página cada una y siempre con un beneficio concreto |
| Longitud | Dentro de los límites de [secciones.md](./secciones.md) o del componente |
| Seguridad de marca | Sin lenguaje sexual explícito, sin menores, sin urgencia falsa, sin descuentos ficticios |
| Consistencia | Misma persona gramatical (tú / usted / ustedes) en todo el sitio |

## 3. Frases y patrones prohibidos (sin beneficio concreto)

- "Vive una experiencia única", "El lugar perfecto para ti", "Momentos inolvidables", "El mejor motel de la ciudad", "Calidad y servicio garantizados", "Lo mejor para ti".
- Superlativos sin evidencia: el mejor, el más, número 1, único en…
- "100 % privado/anónimo/seguro" y garantías de privacidad absolutas.
- "Últimas habitaciones", "Solo hoy", "Oferta imperdible", contadores, % de descuento sin respaldo.
- Lenguaje infantil o diminutivos (cuchi, chiquitito) para público adulto.
- Texto sexual explícito como recurso por defecto.

## 4. Pares positivo / negativo transversales

| Sección | ❌ Antiejemplo | ✅ Corrección (misma intención, con datos) |
| :-- | :-- | :-- |
| Hero | "Bienvenido al mejor motel de la ciudad" | "Suites privadas con jacuzzi, a [minutos] de [zona real]" |
| Habitación | "Una habitación increíble y única" | "Suite [nombre]: cama king, jacuzzi para dos, luz regulable. $[tarifa] por [duración]" |
| CTA | "Más información" | "Consulta disponibilidad por WhatsApp" |
| Privacidad | "Total anonimato garantizado" | "Ingreso independiente y atención con respeto a tu intimidad" |
| Promoción | "¡Solo hoy 50 % off!" | "Tarifa especial de [día] a [día]; consulta condiciones" |
| Visita | "Ven ya, no te lo pierdas" | "Pasa a conocer las suites y elige con calma" |
| FAQ | "Tenemos todo lo que necesitas" | "¿Qué formas de pago aceptan? [Formas reales]. ¿Dudas? Escríbenos por WhatsApp" |

## 5. Protocolo de autocorrección

1. Recorre el texto completo con la lista de §1.
2. Busca con búsqueda de texto las palabras de §3 y las "desaconsejadas" del tono.
3. Cuenta repeticiones de "experiencia / exclusivo / inolvidable / único / perfecto".
4. Revisa que cada dato duro tenga fuente o marcador.
5. Revisa enlaces `wa.me` (solo dígitos) y mapa.
6. Reescribe lo que falle; repite hasta que todo cumpla.
7. En la entrega, informa en ≤ 5 líneas: tono elegido, datos pendientes, supuestos.
